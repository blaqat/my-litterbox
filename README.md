# blaqat.net / aidengreen.me

My Personal website showcasing projects, music compositions, and ways to get in touch.

Built with [Astro](https://astro.build) and [Svelte](https://svelte.dev), featuring a responsive design with Tailwind CSS.

View on https://blaqat.net

## 🚀 Features

- **Projects Portfolio**: Showcase of software engineering projects, including web apps, research, and personal experiments
- **Music Compositions**: Collection of original piano compositions for film, video games, and personal pieces
- **Thoughts & Blog**: (not yet) Personal insights and technical writings
- **Responsive Design**: Optimized for desktop and mobile experiences

## 🛠️ Tech Stack

- **Framework**: Astro + Svelte
- **Styling**: Tailwind CSS
- **Content**: Tailwind Prose + MDX for rich content
- **Deployment**: Cloudflare Pages
- **Languages**: TypeScript

## 🧞 Commands

All commands are run from the root of the project:

| Command           | Action                                           |
| :---------------- | :----------------------------------------------- |
| `pnpm install`    | Installs dependencies                            |
| `pnpm dev`        | Starts local dev server at `localhost:4321`      |
| `pnpm build`      | Build your production site to `./dist/`          |
| `pnpm preview`    | Preview your build locally, before deploying     |

## 📁 Project Structure

```
/
├── public/
│   ├── media/          # Images, videos, and assets
│   └── favicon.svg     # Site favicon
├── src/
│   ├── components/     # Reusable Svelte components
│   │   ├── Music/      # Music player and related components
│   │   ├── Projects/   # Project cards and modals
│   │   └── DeviceType/ # Responsive device components
│   ├── data/           # Static data files (JSON, MDX)
│   ├── layouts/        # Astro layout components
│   ├── lib/            # Utility functions and stores
│   ├── pages/          # Astro page routes
│   ├── styles/         # Global CSS and Tailwind config
│   └── types/          # TypeScript type definitions
├── astro.config.ts     # Astro configuration
├── tailwind.config.mjs # Tailwind CSS configuration
├── svelte.config.ts    # Svelte configuration
└── package.json        # Project dependencies and scripts
```
